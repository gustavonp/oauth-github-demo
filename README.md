# OAuth 2.0 demo

This is a simple implementation of an OAuth protocol.

# Explanation

Here, I'm just making a simple call to GitHub to use its Access Token to return some of your personal information.

Open http://localhost:5173 and click **Login with GitHub**.

**Stack:** React + TypeScript (Vite), Express + TypeScript, `express-session`

# Requirements
- Github account
- GitHub's OAuth `client_id` (see .env.example)
- GitHub's OAuth `client_secret` (see .env.example)
